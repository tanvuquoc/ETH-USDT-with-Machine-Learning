# ETH-USDT-with-Machine-Learning
Dự án này tập trung nghiên cứu, thiết kế và kiểm định (backtest) một chiến lược giao dịch định lượng trên cặp tiền điện tử ETH/USDT. Thay vì giao dịch dựa trên cảm tính hoặc các chỉ báo kỹ thuật rule-based đơn lẻ, dự án ứng dụng Machine Learning (Logistic Regression &amp; XGBoost) để dự báo xu hướng thị trường và tối ưu hóa quyết định đầu tư.
